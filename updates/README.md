# OS Hero Updates

This directory is the public electron-updater generic feed for OS Hero.
Current release version: 0.1.13

macOS auto-update is temporarily held at 0.1.12 because ad-hoc signed builds do
not satisfy Squirrel.Mac signature validation across versions. Use manual macOS
install for 0.1.13 until Developer ID signing/notarization is configured.

Do not hand-edit latest*.yml files. They are generated by electron-builder.
