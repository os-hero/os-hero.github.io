# OS Hero Updates

This directory is the public electron-updater generic feed for OS Hero.
Current release version: 0.1.13

macOS, Windows, and website downloads all point to the current release. Until
Developer ID signing/notarization is configured, some ad-hoc signed macOS
installs may need a manual reinstall instead of in-app auto-update.

Do not hand-edit latest*.yml files. They are generated by electron-builder.
