# OS Hero Website

This repository hosts the public OS Hero website and the electron-updater generic feed.

- App source repository: https://github.com/os-hero/os-hero
- Website: https://os-hero.github.io/
- Update feed: https://os-hero.github.io/updates/

The root website is a static multilingual download site. The `updates/` directory contains versioned installers plus `latest*.yml` metadata generated by electron-builder.
Builds and update artifacts are generated from the app source repository, then copied here by `scripts/deploy-updates.js`.
